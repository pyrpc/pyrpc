# pyRPC × Flask × React

Full-stack example: Flask backend + React frontend, connected by pyRPC.

## Setup

```bash
# 1. Install Python dependencies
cd server
pip install "pyrpc-core[flask]" flask-cors

# 2. Install frontend dependencies  
cd ../client
npm install
```

## Development

```bash
# Terminal 1 - type generation watcher
cd server
pyrpc watch --module main --client ../client

# Terminal 2 - Flask server on http://localhost:5000
cd server
python main.py

# Terminal 3 - React development server
cd client
npm start
```

## Architecture

- **Backend**: Flask with pyRPC procedures in `server/`
- **Frontend**: React with TanStack Query in `client/`
- **Type Safety**: End-to-end TypeScript types generated by pyRPC

## Key Files

- `server/main.py` - Flask app with @rpc procedures
- `client/src/pyrpc.ts` - pyRPC client configuration  
- `client/src/` - React application code
