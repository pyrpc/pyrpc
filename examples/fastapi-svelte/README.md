# pyRPC × FastAPI × Svelte

Full-stack example: FastAPI backend + Svelte frontend, connected by pyRPC.

## Setup

```bash
# 1. Install Python dependencies
cd server
pip install pyrpc-core[fastapi]

# 2. Install frontend dependencies  
cd ../client
npm install
```

## Development

```bash
# Terminal 1 - FastAPI server with type generation
cd server
pyrpc dev

# Terminal 2 - Svelte development server
cd client  
npm run dev
```

## Architecture

- **Backend**: FastAPI with pyRPC procedures in `server/`
- **Frontend**: Svelte with TanStack Query in `client/`
- **Type Safety**: End-to-end TypeScript types generated by pyRPC

## Key Files

- `server/main.py` - FastAPI app with @rpc procedures
- `client/lib/pyrpc.ts` - pyRPC client configuration  
- `client/src/` - Svelte application code
