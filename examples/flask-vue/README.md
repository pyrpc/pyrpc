# pyRPC × Flask × Vue

Full-stack example: Flask backend + Vue frontend, connected by pyRPC.

## Setup

```bash
# 1. Install Python dependencies
cd server
pip install pyrpc-core[flask]

# 2. Install frontend dependencies  
cd ../client
npm install
```

## Development

```bash
# Terminal 1 - Flask server with type generation
cd server
pyrpc dev

# Terminal 2 - Vue development server
cd client  
npm run dev
```

## Architecture

- **Backend**: Flask with pyRPC procedures in `server/`
- **Frontend**: Vue with TanStack Query in `client/`
- **Type Safety**: End-to-end TypeScript types generated by pyRPC

## Key Files

- `server/main.py` - Flask app with @rpc procedures
- `client/lib/pyrpc.ts` - pyRPC client configuration  
- `client/src/` - Vue application code
