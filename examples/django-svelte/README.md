# pyRPC × Django × Svelte

Full-stack example: Django backend + Svelte frontend, connected by pyRPC.

## Setup

```bash
# 1. Install Python dependencies
cd server
pip install "pyrpc-core[django]" django-cors-headers

# 2. Install frontend dependencies  
cd ../client
npm install
```

## Development

```bash
# Terminal 1 - type generation watcher
cd server
pyrpc watch --module myproject.views --client ../client

# Terminal 2 - Django server on http://localhost:8000
cd server
python manage.py runserver

# Terminal 3 - Svelte development server
cd client
npm run dev
```

## Architecture

- **Backend**: Django with pyRPC procedures in `server/`
- **Frontend**: Svelte with TanStack Query in `client/`
- **Type Safety**: End-to-end TypeScript types generated by pyRPC

## Key Files

- `server/manage.py` - Django management script
- `server/myproject/views.py` - Django views with @rpc procedures
- `client/src/lib/pyrpc.ts` - pyRPC client configuration  
- `client/src/` - Svelte application code
