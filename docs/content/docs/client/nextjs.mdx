# Next.js / TypeScript Client

Use `pyRPC-codegen` to generate a typed TypeScript client for your pyRPC procedures.

## Generate the Client

From your Python project:

```bash
uv add pyrpc-codegen

pyrpc codegen -m my_app.main -o src/lib/pyRPC-client.ts
```

This scans registered procedures in `my_app.main` and generates a `pyRPCClient` class.

## Using pyRPCClient

```ts
import { pyRPCClient } from "@/lib/pyRPC-client";

const client = new pyRPCClient(process.env.NEXT_PUBLIC_API_URL!);

export async function addExample() {
  const result = await client.add(1, 2);
  console.log(result);
}
```

Under the hood, `pyRPCClient`:

- Sends `POST /rpc` requests to your server.
- Sends `{"id", "method", "params"}` JSON.
- Throws `pyRPCError` when the server returns an error.

## In Next.js Components

Use it inside server actions or React components as you would any fetch‑based client. For example, in a server action:

```ts
"use server";

import { pyRPCClient } from "@/lib/pyRPC-client";

const client = new pyRPCClient(process.env.pyRPC_API_URL!);

export async function createUserAction(formData: FormData) {
  const name = formData.get("name") as string;
  const email = formData.get("email") as string;
  return client.createUser(name, email);
}
```

## Error Handling

The generated client throws:

- `pyRPCError` when the RPC returns an error.
- Standard `Error` when the HTTP request fails.

```ts
import { pyRPCClient, pyRPCError } from "@/lib/pyRPC-client";

const client = new pyRPCClient(process.env.NEXT_PUBLIC_API_URL!);

try {
  const user = await client.getUser(1);
} catch (e) {
  if (e instanceof pyRPCError) {
    console.error(e.code, e.message);
  } else {
    console.error("Network error", e);
  }
}
```
