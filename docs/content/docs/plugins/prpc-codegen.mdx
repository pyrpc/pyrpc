# pyrpc-codegen

Automatically generate a TypeScript types interface from your pyRPC server definition.

## Installation

```bash
# CLI + runtime + codegen (recommended - one install, everything)
pip install pyrpc-core

# Or just the codegen library (for standalone use without runtime)
pip install pyrpc-codegen
```

## Quick Setup

The `@pyrpc/types` package runs a setup prompt automatically when you install `@pyrpc/client`:

```bash
npm install @pyrpc/client
```

If you're in an interactive terminal, it will prompt for your backend URL,
fetch the schema, and generate types. In CI, set the `PYRPC_URL` environment
variable to skip the prompt.

```bash
PYRPC_URL=https://api.example.com npm install @pyrpc/client
```

## CLI Usage

The `pyrpc` CLI (included with `pyrpc-core`) provides these subcommands:

| Command | Description |
|---------|-------------|
| `pull`  | Extract RPC schema from a Python module and save as JSON |
| `codegen` | Generate TypeScript types from a schema file or running server |
| `serve` | Start the pyRPC ASGI server |
| `inspect` | List all registered RPC procedures in a module |
| `version` | Show pyRPC version |

### `pyrpc pull`

Extract the RPC schema from your Python module into a JSON file:

```bash
pyrpc pull my_app.main -o pyrpc-schema.json
```

This is useful for CI workflows — commit the schema file to your repo so
frontend builds can generate types without a running Python server:

```bash
git add pyrpc-schema.json
git commit -m "chore(codegen): update RPC schema"
```

> **For frontend projects:** Just `npm install @pyrpc/client`. The postinstall
> script prompts for your server URL and generates types automatically.
> No CLI needed.

### `pyrpc codegen`

Generate TypeScript types from a schema file:

```bash
pyrpc codegen pyrpc-schema.json
```

Or directly from a running server (no `pull` required):

```bash
pyrpc codegen http://localhost:8000
```

Use `--output` to write to a custom path:

```bash
pyrpc codegen pyrpc-schema.json --output ./src/pyrpc-types.ts
```

### Full Workflow (CLI)

```bash
# Install everything
pip install pyrpc-core

# Pull schema from your Python module (for CI/offline)
pyrpc pull my_app.main -o pyrpc-schema.json

# Generate types from the schema file
pyrpc codegen pyrpc-schema.json

# Or skip the file and use a running server
pyrpc codegen http://localhost:8000
```

For frontend-only projects, skip this entirely and just install the client:

```bash
npm install @pyrpc/client
```

The install prompts for your server URL and handles codegen automatically.

## Features

TypeScript types interface generation  
Full type inference (int ↔ number, str ↔ string, etc.)  
Postinstall setup  -  one command installs and configures  
Documentation comments  

## Generated Output

```typescript
// node_modules/@pyrpc/types/src/index.ts
export interface Types {
  add(a: number, b: number): Promise<number>;
  greet(name: string): Promise<string>;
}
```

Use it with `@pyrpc/client`:

```typescript
import { createClient } from "@pyrpc/client"
import type { Types } from "@pyrpc/types"

const client = createClient<Types>({ baseUrl: "http://localhost:8000" })
const result = await client.add(10, 5) // Fully typed, with autocompletion!
```
