# Plugins

pyRPC plugins are **extensions** that add behavior or tooling on top of the core protocol and adapters.

## Available Plugins

<Card title="Code Generation" href="/docs/plugins/pyrpc-codegen">
  Generate TypeScript or Python client SDKs from your pyRPC router
</Card>

## Installation

Install plugins alongside the core `pyRPC` package as needed:

```bash
pip install pyrpc-core pyrpc-codegen
```
