# Sponsors

pyRPC is MIT-licensed and maintained by [@atnatewos](https://github.com/atnatewos). Sponsorship directly funds:

- Maintenance of `pyrpc-core`, `pyrpc-codegen`, and all adapter packages
- New framework adapter development (Nuxt, SvelteKit, Astro, and more)
- Documentation, examples, and the interactive demo sandbox
- CI infrastructure and release tooling

## How to support

**Star the repo** - the fastest way to increase visibility and help other developers discover pyRPC:
[github.com/pyrpc/pyrpc](https://github.com/pyrpc/pyrpc)

**Report issues and suggest features** - good bug reports and well-scoped feature requests are a real form of contribution:
[github.com/pyrpc/pyrpc/issues](https://github.com/pyrpc/pyrpc/issues)

**Contribute code** - see the [Contributing guide](/docs/community/contributing) for setup instructions and scope guidelines.

**Sponsor financially** - reach out on [Telegram](https://t.me/pyrpc) or [X](https://x.com/pyrpc_dev) to discuss sponsorship. GitHub Sponsors support coming soon.
