# Django Adapter

The Django adapter uses Django's native `async def` views — no sync wrapper needed. Register procedures in `views.py`, import that module in `urls.py`, and call `mount_django()` to wire everything up.

## 1. Install

```bash
uv add pyrpc-core[django]
# or
pip install "pyrpc-core[django]"
```

## 2. Write the server

```python
# myproject/views.py
from django.http import HttpResponse
from pyrpc_core import rpc

def index(request):
    return HttpResponse("<h1>Django + pyRPC</h1>")

@rpc.query
async def greet(name: str = "World") -> dict:
    return {"message": f"Hello, {name}!", "framework": "Django"}

@rpc.query
async def read_item(item_id: int, q: str = None) -> dict:
    return {"item_id": item_id, "q": q}

@rpc.mutation
async def create_item(name: str, description: str = None) -> dict:
    return {"name": name, "description": description, "created": True}
```

```python
# myproject/urls.py
from django.urls import path, include
from . import views  # this import triggers @rpc registration

urlpatterns = [
    path("", views.index),
    path("rpc/", include("pyrpc_django_adapter.urls")),
]
```

> **Important:** importing `views` in `urls.py` is what executes the `@rpc` decorators. Without that import, procedures are never registered and `/rpc` returns an empty schema.

Add CORS for local frontend development. Install `django-cors-headers`:

```bash
uv add django-cors-headers
```

Then in `settings.py`:

```python
INSTALLED_APPS = [
    "corsheaders",
    # ...
]

MIDDLEWARE = [
    "corsheaders.middleware.CorsMiddleware",  # must be before CommonMiddleware
    "django.middleware.common.CommonMiddleware",
    # ...
]

CORS_ALLOWED_ORIGINS = [
    "http://localhost:3000",   # React / Next.js
    "http://localhost:5173",   # Vue / Svelte (Vite)
]
```

## 3. Start the dev server

From your Django project root:

```bash
pyrpc dev
```

First run: 2-question wizard, writes `pyrpc.json`. Subsequent runs: reads it automatically. To skip the wizard:

```bash
# auto-detect
pyrpc dev --yes

# explicit — point at the views module
pyrpc dev --yes --module myproject.views --output ../client/src/__pyrpc.d.ts
```

## 4. Connect the frontend

```ts
// lib/pyrpc.ts (React)
import { createReactClient } from "@pyrpc/react"
import type { Types } from "@pyrpc/types"

export const api = createReactClient<Types>({ baseUrl: "http://localhost:8000" })
```

See [React](/docs/client/react), [Next.js](/docs/client/nextjs), [Vue](/docs/client/vue), or [Svelte](/docs/client/svelte) for full frontend setup.

## How it works

- `@rpc.query` / `@rpc.mutation` register the **async** function in the global registry.
- `path("rpc/", include("pyrpc_django_adapter.urls"))` wires two URL patterns:
  - `POST /rpc/` — procedure dispatch (native async view)
  - `GET /rpc/` — schema introspection (used by `pyrpc dev`)
- Procedures are `async def` because Django 4.2+ handles async views natively. No `anyio.run` bridge.
- The `from . import views` line in `urls.py` is required — it's what triggers decorator execution.

## Requirements

- Django 4.2+
