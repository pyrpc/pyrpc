pyRPC follows a modular packaging strategy. You only pay for what you use.

## Core Package

The tiny core protocol and runtime. This is always required.

```bash
# Using uv
uv add pyrpc-core

# Using pip
pip install pyrpc-core
```

## Adapters

Install the adapter for your favorite web framework.

### FastAPI

```bash
uv add pyrpc-fastapi
```

### Flask

```bash
uv add pyrpc-flask
```

## CLI & Code Generation

The `pyrpc` CLI comes built-in with `pyrpc-core` — no separate install needed.

### Contract Synchronization

The frontend package generates types automatically on install:

```bash
npm install @pyrpc/client
```

The postinstall script prompts for your server URL, fetches the schema from `GET /rpc`, and writes types to `node_modules/@pyrpc/types/src/index.ts`.

For server-side or CI workflows, the CLI can generate types explicitly:

```bash
uv run pyrpc codegen http://localhost:8000
```

## Quick Start Example (FastAPI)

```python
from fastapi import FastAPI
from pyrpc_core import rpc
from pyrpc_fastapi import mount_fastapi

app = FastAPI()

@rpc
def add(a: int, b: int) -> int:
    return a + b

mount_fastapi(app)
```
