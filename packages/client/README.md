# @pyrpc/client

Universal TypeScript client for [pyRPC](https://pyrpc.com). Type-safe RPC calls to your Python backend - install, import, call.

## Installation

```bash
npm install @pyrpc/client
# or
pnpm add @pyrpc/client
# or
bun add @pyrpc/client
```

Types are generated by the server-side `pyrpc dev` / `pyrpc watch` / `pyrpc codegen` commands into `<client>/__pyrpc.ts`, and resolved via a tsconfig path alias that `pyrpc dev` injects into your `tsconfig.json` (using jsonc-edit). No install-time steps required.

## Usage

```typescript
import { createClient, httpLink, type Types } from "@pyrpc/client";

const client = createClient<Types>({
  links: [httpLink({ url: "https://api.example.com" })],
});

const user = await client.get_user(1);
console.log(user.name); // Fully typed - no manual type definitions needed
```

The proxy-based API lets you call any remote procedure as a local method. Parameters are passed positionally or as a single object for named arguments.

The link URL can be the server root (`https://api.example.com`) or the full endpoint (`https://api.example.com/rpc`); it normalizes to `/rpc`.

### Batching

Use `httpBatchLink` to combine concurrent operations into a single request:

```typescript
import { createClient, httpBatchLink, type Types } from "@pyrpc/client";

const client = createClient<Types>({
  links: [httpBatchLink({ url: "https://api.example.com", maxItems: 10 })],
});

const [a, b] = await Promise.all([client.add(1, 2), client.mul(3, 4)]);
// Both operations ship in one HTTP request
```

### Error handling

```typescript
import { createClient, httpLink, PyRPCError } from "@pyrpc/client";

try {
  await client.delete_user(1);
} catch (error) {
  if (error instanceof PyRPCError) {
    console.error(error.code, error.message);
  }
}
```

## API

### `createClient<T>(options)`

Creates a proxy client that forwards method calls to the server. The generic parameter `T` is your `Types` interface for full type safety.

- `links` - Link pipeline. Exactly one terminating link (`httpLink` or `httpBatchLink`); zero or multiple is a configuration error.

### `httpLink({ url })`

Sends one RPC operation per HTTP request to the server's `/rpc` endpoint.

### `httpBatchLink({ url, maxItems? })`

Combines RPC operations that occur close together into one HTTP request. Operations execute sequentially on the server; each keeps its own result or error. `maxItems` flushes the batch early (defaults to `Infinity`).

Both links accept the server root or the full `/rpc` endpoint and normalize to `/rpc`.

**Note:** There is no `.rpc` property. Call methods directly on the client object.
