# @pyrpc/types

TypeScript type definitions for [pyRPC](https://pyrpc.dev). Generated by `pyrpc dev` or `pyrpc codegen` — reflects your actual Python backend procedures at compile time.

## How it works

`@pyrpc/types` is a dependency of `@pyrpc/client`. Types are generated by the server-side `pyrpc dev` command or `pyrpc codegen`:

```bash
# Start the dev server (generates types automatically)
pyrpc dev

# Or generate manually from a running server
pyrpc codegen http://localhost:8000
```

By default, types are written to `{client_root}/node_modules/@pyrpc/types/src/index.ts`, where `client_root` is configured in `pyrpc.json`.

Before codegen runs, `Types` resolves to an empty interface. After codegen, it resolves to your actual procedure signatures — full autocompletion, no boilerplate.

## Manual generation

```bash
pyrpc codegen http://localhost:8000
```
